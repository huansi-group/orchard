# DataAgent 需求分析与功能设计（面向中小企业）

> 版本：v1.1 · 2026-11-04  
> 状态：评审稿  
> 来源：[GitHub Issue #4](https://github.com/huansi-group/orchard/issues/4)  
> 范围：产品需求、功能设计、分期方案；**本次不改动代码**

## 1. 一页结论

- **定位**：面向中小企业的轻量 DataAgent 工作台，不建重型数据中台，不追求多智能体自治。
- **主线**：以业务数据库/Excel 为源，以元数据、标注、指标语义为可信基础，以会话式分析为入口，以 SQL 审计和细粒度权限为底线，以反馈评测驱动持续变准。
- **架构**：模块化单体 + 一个元数据库 + 一个统一 SQL 网关 + 一个 Agent 运行时；默认虚拟查询，按需物化。
- **关键取舍**：语义编译优先、纯 NL2SQL 兜底；权限进入执行链路；审计失败即拒绝；每期独立闭环。
- **分期**：Phase 0 准备（2 周）→ Phase 1 可用问数 + 定时任务（9–11 周）→ Phase 2 数据闭环与治理（8–10 周）→ Phase 3 规模化（8–12 周）。

## 4. 关键设计结论

### 4.1 六个必须做对的点

1. **统一指标口径**：核心指标必须有唯一名称、公式、负责人、版本；同名冲突拦截。
2. **语义优先**：先用“指标 + 维度 + 过滤 + 时间”编译 SQL；自由 SQL 只作探索兜底。
3. **权限进网关**：表/列/行权限在 SQL 执行前校验与改写，默认拒绝；智能体范围不得超过用户权限。
4. **SQL 全量审计**：记录 SQL、执行人、结果、耗时、风险；审计写入失败则拒绝查询。
5. **数据闭环**：元数据/标注/语义/血缘不是展示页，而是模型上下文与影响分析的基础。
6. **反馈评测**：没有评测集与坏例闭环，准确率无法持续；每期设发布门禁。

### 4.2 十个核心模块

```text
数据接入 → 轻量 ETL/质量 → 元数据与标注 → 语义与指标 → 数据血缘
                                              ↓
                     会话式分析 Agent ← 统一 SQL 网关 → 权限/审计
                          ↓
                    定时任务 → 结果快照 / 通知
                                              ↓
                                    反馈、评测与运营
```

- 首期落地：数据接入、元数据标注、语义指标、会话、SQL 审计、基础权限、定时问数（站内通知）。
- 二期补齐：ETL、质量、血缘、行/列权限、访问审批、评测/坏例、邮件/Webhook 推送。
- 三期扩展：多源、报告/IM/第三方推送/API、归因、SSO、多租户、成本。

### 4.3 三个闭环

| 闭环 | 链路 | 验证 |
| --- | --- | --- |
| 数据闭环 | 接入 → 同步/ETL → 元数据 → 标注 → 语义 → 血缘 → 反馈 | 一条源表到指标的链路可追溯 |
| 回答闭环 | 问题 → 澄清 → 检索 → 编译/生成 → 权限 → 执行 → 图表/解读 → SQL → 反馈 | 答案可解释、可复核 |
| 治理闭环 | 身份 → 权限 → SQL 网关 → 审计 → 风险 → 审批/告警 → 策略优化 | 越权 0、审计 100% |

## 7. 范围与非目标

**本期范围**：MySQL/PostgreSQL/CSV 接入、元数据与标注、语义指标、会话问数、SQL 审计、基础 RBAC、定时问数、轻量 ETL、血缘、行/列权限、评测闭环。

**明确不做**：自研大模型、完整湖仓、实时流计算、复杂 DAG、MDM、ML 平台、原生 App、数据交易、多智能体自治；一期不做邮件/Webhook/IM/第三方推送。

## 8. 术语表

| 术语 | 含义 |
| --- | --- |
| DataAgent | 面向企业数据的分析型智能体：理解问题、规划、调用工具、给出可解释答案 |
| NL2SQL | 自然语言转 SQL |
| NL2Semantics | 自然语言先映射到指标/维度/语义模型，再编译 SQL |
| 语义层 | 描述业务指标、维度、口径、Join 的模型层 |
| 元数据 | 描述数据的数据：表、字段、类型、注释、负责人等 |
| 数据标注 | 为表/字段补充业务名、描述、同义词、枚举、敏感级别 |
| 数据血缘 | 数据从源到目标的加工关系，支持影响分析 |
| SQL 网关 | 统一做 SQL 校验、权限改写、执行、限流、审计的组件 |
| 定时任务 | 将保存的问数按 Cron 定时执行，留存结果并通知的调度能力 |
| RBAC / ABAC | 基于角色 / 基于属性的访问控制 |
| 行级权限 | 按用户属性过滤数据行 |
| 列级权限 | 控制字段可见、脱敏、隐藏 |
| 坏例 | 用户反馈或评测发现的错误回答，进入修复闭环 |
| Golden Set | 人工确认的评测问题集，用于回归 |
